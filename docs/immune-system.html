Immune System

Two-layer defense: innate (fast, pattern recognition, complement, IFN) and adaptive (antigen-specific T/B lymphocytes, immunological memory). Peak adaptive response 7–14 days first exposure; memory recall 2–3 days. Organized around lymphoid organs.

Also known as: immunity, immune response, lymphoid system, humoral immunity, cellular immunity
