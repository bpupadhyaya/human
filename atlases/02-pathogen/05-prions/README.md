# Class 05 — Prions

Misfolded protein pathogens. PrPSc (scrapie prion protein) is an aberrantly folded isoform of the normal cellular PrPC that propagates by templating its conformation onto native PrPC, resisting proteolysis and accumulating in neural tissue as amyloid plaques. Cause transmissible spongiform encephalopathies (TSEs): Creutzfeldt–Jakob disease, kuru, bovine spongiform encephalopathy, scrapie. No nucleic acid genome. No effective treatment.
