# Platform 02 — Viral-Vector Vaccines

### Replication-deficient adenoviral and other viral-vector vaccines

**[← Vaccine Atlas](../README.md)** · **[← Atlases index](../../README.md)**

</div>

---

Viral-vector vaccines deliver a pathogen antigen gene inside a modified, replication-deficient virus — typically a chimpanzee adenovirus (ChAdOx), human adenovirus serotype 5 (Ad5) or 26 (Ad26), or modified vaccinia Ankara (MVA). The vector infects host cells, which then transcribe and translate the antigen, triggering both humoral and robust T-cell immunity without genomic integration.

**Key advantages over mRNA:**
- Refrigerator-stable (2–8°C) for standard cold-chain deployment
- Strong CD8⁺ T-cell responses via intracellular antigen presentation
- Established manufacturing in developing-country facilities

**Key tradeages:**
- Pre-existing anti-vector immunity reduces immunogenicity (e.g., Ad5 seroprevalence >50% in many populations)
- Rare serious adverse events: VITT with ChAdOx1 platforms, cerebral venous thrombosis
